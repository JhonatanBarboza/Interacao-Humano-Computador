# Interação Humano-Computador

**Patas que Acolhem** — protótipo de uma plataforma web que centraliza a divulgação de animais para adoção de múltiplas ONGs/abrigos. Adotantes podem buscar e filtrar animais; cada instituição gerencia seus cadastros e sua página institucional. Projeto da disciplina de Interação Humano-Computador.

## Estrutura do repositório

| Pasta | Conteúdo |
| --- | --- |
| [`Docs/`](Docs) | Pitch, requisitos, personas, análise de tarefas e entregas da disciplina |
| [`Wireframes/`](Wireframes) | Wireframes de baixa fidelidade (imagens) |
| [`Wireframes de alta fidelidade/`](Wireframes%20de%20alta%20fidelidade) | Protótipo navegável de alta fidelidade (React + Vite, sem backend) |

Os wireframes também estão no [Figma](https://www.figma.com/design/N2o8I8Gbi9GD1ytwcNbeQT/Sem-t%C3%ADtulo?node-id=0-1&p=f&t=mhOMHN7zE7jtLC9A-0).

## Como rodar o protótipo

Requer [Node.js](https://nodejs.org) instalado.

```bash
cd "Wireframes de alta fidelidade"
npm install
npm run dev
```

Depois, abra o endereço exibido no terminal (por padrão, http://localhost:5173). Mais detalhes em [Wireframes de alta fidelidade/README.md](Wireframes%20de%20alta%20fidelidade/README.md).
